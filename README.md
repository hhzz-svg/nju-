# NJU 高级程序设计 PA 大作业：自走棋项目

这是南京大学（NJU）智能科学技术学院《高级程序设计》课程的 PA 大作业项目。项目以 Qt6 + C++17 实现了一个轻量级自走棋原型，覆盖棋盘交互、自动战斗、商店购买、羁绊加成、装备、存档读档和测试验证等模块。

这个仓库主要用于课程项目归档，也希望给未来的学弟学妹提供一个可参考的实现样例：重点不是照抄代码，而是理解一个中等规模 C++/Qt 项目如何拆模块、如何逐步交付、如何把 OOP、数据结构、GUI 交互和测试组织在一起。

## 项目要点

- **课程背景**：NJU 智能科学技术学院《高级程序设计》PA 大作业。
- **项目主题**：回合制自走棋 Auto-Battler 原型。
- **技术栈**：C++17、Qt6 Widgets、CMake。
- **核心循环**：准备阶段买棋和布阵，战斗阶段自动寻敌和释放技能，结算阶段处理金币、经验和血量。
- **设计目标**：用尽量清楚的模块边界完成可运行、可演示、可解释的课程项目。

## 已实现功能

- 8x8 棋盘与玩家/敌方半场区分。
- 棋子拖拽部署、位置合法性校验和备战席交互。
- 自动战斗系统：寻敌、移动、普攻、技能释放、胜负结算。
- 商店系统：随机刷新、购买棋子、金币消耗。
- 玩家成长：金币、经验、等级、血量。
- 羁绊系统：按上场单位统计并提供属性加成。
- 三合一升星与基础装备加成。
- 存档/读档：使用 JSON 保存和恢复游戏状态。
- GUI 反馈：棋盘颜色、棋子图标、血条、攻击线和伤害飘字。
- 单元测试：覆盖棋盘、战斗、商店、羁绊、装备和交互回归场景。

```text
│   └── main.cpp

```

## 架构说明

项目按三层拆分：

- `entity/`：保存单位、装备、羁绊等基础数据结构，尽量不依赖界面。
- `core/`：承载主要业务规则，例如棋盘占位、战斗推进、商店刷新、玩家状态和存档。
- `gui/`：负责 Qt 界面展示和鼠标交互，通过信号槽把用户操作传给核心逻辑。

这个拆法适合课程 PA：规模不大，但足够展示面向对象设计、模块分工、数据结构使用和可测试性。

## 构建方式

需要本机安装 Qt6、CMake 和支持 C++17 的编译器。

```bash
cmake -S . -B build
cmake --build build
```

运行主程序：

```bash
./build/Synera_Starter
```

Windows 下也可以直接使用 `bin/Synera_Starter.exe`。如果运行环境缺少 Qt 动态库，请在 Qt Creator 中打开项目运行，或将 Qt 的运行时目录加入 `PATH`。

## 测试

项目包含两个测试目标：

```bash
cmake --build build --target Synera_Starter_CombatTests
cmake --build build --target Synera_Starter_Week4Tests
ctest --test-dir build
```

测试覆盖重点：

- 棋盘放置、移动和占位关系。
- 战斗寻敌、攻击、技能和胜负判断。
- 商店购买、经济系统和备战席。
- 羁绊、装备、升星和拖拽交互回归。

## 给后来者的参考建议

如果你正在做类似 PA，可以重点看这些地方：

- `src/core/game.cpp`：整体流程控制，适合理解一个游戏回合如何串起来。
- `src/core/combat.cpp`：自动战斗、寻敌和行动推进。
- `src/core/board.cpp`：棋盘坐标和单位占位管理。
- `src/gui/gamewindow.cpp`：Qt Widgets 的界面组织方式。
- `tests/`：如何用小测试保护核心规则。

建议先跑起来，再顺着“准备阶段 -> 战斗阶段 -> 结算阶段”的流程读代码。不要一上来逐行啃 GUI，先理解数据和状态怎么流动，会轻松很多。
